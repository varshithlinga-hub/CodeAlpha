# CodeAlpha FAQ Chatbot

This is a simple FAQ chatbot created for the CodeAlpha Artificial Intelligence Internship.

## Features
- User can ask questions
- Preprocesses text using NLP
- Matches user question with stored FAQs
- Uses TF-IDF and cosine similarity
- Displays the best matching chatbot response
- Simple Streamlit web interface

## Technologies Used
- Python
- Streamlit
- NLTK
- scikit-learn
- TF-IDF
- Cosine Similarity
