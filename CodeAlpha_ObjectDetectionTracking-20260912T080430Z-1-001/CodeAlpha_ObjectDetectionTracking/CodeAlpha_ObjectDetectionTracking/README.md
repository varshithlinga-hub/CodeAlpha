# CodeAlpha Object Detection and Tracking

This project is created for the CodeAlpha Artificial Intelligence Internship.

## Project Description

This project performs real-time object detection and tracking using a webcam. It uses a pre-trained YOLO model to detect objects and OpenCV to display the output with bounding boxes, class labels, confidence scores, and tracking IDs.

## Features

- Real-time webcam input
- Object detection using YOLO
- Bounding boxes around detected objects
- Object labels and confidence scores
- Tracking IDs for detected objects
- Press `q` to close the camera window

## Technologies Used

- Python
- OpenCV
- Ultralytics YOLO
